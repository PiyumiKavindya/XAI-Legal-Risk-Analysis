> **VI.** **CONCLUSION**

This project successfully developed an AI framework for the automated
analysis of legal documents. It integrates a high-performance,
fine-tuned BERT model for classifying clauses and a GPT model for
generating actionable suggestions. A key achievement of this work is the

in-application evaluation suite. These features directly address the
need for transparency, accountability, and verifiable performance in
legal technology. The analytical approach proved effective, achieving a
weighted F1-Score of 0.849. Additionally, the successful implementation
of interactive dashboards for privacy, fairness, and model evaluation

truly advanced and trustworthy AI solution. The "Legal Analyzer" serves
